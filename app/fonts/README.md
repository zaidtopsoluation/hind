# material-symbols-subset.woff2

Material Symbols Outlined, cut down to only the icons this site uses (about 6 KB instead of about 1 MB).

To add a new icon, add its name (in alphabetical order) to `icon_names=` below, open the URL in Chrome, download the `.woff2` file it links to, and replace this file:

https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@400,0..1&icon_names=ac_unit,ad_units,air,apartment,arrow_forward,build,call,check_circle,close,format_quote,handyman,hvac,language,location_on,mail,menu,propane,schedule,share,shield,speed,splitscreen,star,support_agent,verified,verified_user,warning,water_drop,workspace_premium&display=block

An icon missing from the subset shows up as its name in plain text.
